**决议（研究者，2026-10-20）**

本票按[「"更简单"按什么衡量」](https://github.com/DengZhiyuan-math/proof-cli/issues/269)的状态模型和[按新状态模型定稿 54 项去向并重算](https://github.com/DengZhiyuan-math/proof-cli/issues/272)的去向，定已有项目怎样换到新状态模型。研究者说明：目前的重点是验证系统的稳定性，不是真的证明，所以换的过程从简。本轮不修改任何研究项目。

**1. 已接受的节点和已审的导入结果**：证明层都是专家验证过。Reference review 通过的导入结果、Trust rule 覆盖的导入结果都包括在内。换的时候不自动封存，研究者换完后自己决定封存哪些。

**2. 被拒绝的节点**：新模型没有 Rejected。
- 已经没有任何东西靠它的：只算历史，代理不碰它，当初的理由留作记录。
- 还有东西靠它的：变成一条研究者提出的质疑，附上当初的理由。用到它的那一支先停下，由 Coordinator 找研究者讨论怎么了结：封存为错、改出新版本、改依赖，或者撤回。
- 不把它们全部封存为错，因为拒绝往往只说明证明思路走不通，不等于命题为假。也不自动删掉依赖它们的边，因为那等于替研究者改证明结构。

**3. 没了结的 Challenge**：变成同一提出者的质疑，原文保留。
- Coordinator 读原文，归为针对命题或针对证明。只有一种读法时直接归类，并写下"我理解为……"。几种读法后果不同时，先问研究者；回答之前，这个节点不算对，用到它的那一支停着。
- 第 2 条里由被拒节点变来的质疑，也按这个办法归类。
- 已了结的 Challenge 只留作记录。
- 合成例子：L3 上的 Challenge 是"第 3 步用到的紧性条件没有验证"，只有一种读法，归为针对证明，L3 退回未完成。L4 上的 Challenge 是"L4 可能不成立"，两种读法后果不同，所以先问。

**4. 旧规则下的 Verifier 判定**：不算新规则下的检查。
- 没被接受、但判过通过的节点，证明层是未完成。下一次 Pursue 时，Prover 补上"依赖的使用"，交给新的 Verifier 判。旧判定留在工作记录里。重新判过之前，这些节点不再是 Provisional，靠它们的节点也不再是 Conditional（都是现算）。
- 没通过的判定里的旧异议，原文进 briefing，下一份通过的判定要回应它们。"漏写一条就不收"只管新格式的异议，旧异议不拦，因为要拦就得解析判定正文。
- 因此不会有"按旧规则通过"的节点，页面不需要为此另加说明。

**5. 不用转换的**（都已经是现算或记录）
- Standing question：没回答的，研究者直接跟 Coordinator 说。回答和代理的选择不同时，作为 redirect 交给那个节点的下一轮。
- Parked、Provisional、Conditional，以及文字是否固定，都是现算。旧的接受和 Reference review 算验证，被它们依赖过的文字照旧不让代理改。
- 判为 no longer callable 的导入结果：封存为错，按「按新状态模型定稿 54 项去向并重算」定的去向。
- 陈述里指向别处的措辞：机械检查标出其中的节点 id，只作为给 Verifier 的提示，见[节点的条件必须写清楚](https://github.com/DengZhiyuan-math/proof-cli/issues/261)。
- assumptions 不在 proof.tex 里的节点：由 briefing 送到，见[assumptions 和定义送到读的人手里](https://github.com/DengZhiyuan-math/proof-cli/issues/266)。
- git 跟踪的 `reviews.jsonl` 不改写：旧的接受读作验证，旧的拒绝读作历史。被删掉的操作（迁移依赖、轻量复审、Evidence review）留下的记录作为历史保留，以后不再有东西读它们。

**6. 怎么换**（研究者交给我定）

按地图常设约束第 2、4 条，不设专门的迁移流程，中间步骤不要求确认。
- 新版本第一次打开旧项目时，按以上各条自动换一次。换完在工作记录里写一条，说明换了什么、各项多少个，并留一份旧数据库的副本，供排查问题用。
- 换之前的运行不接着跑，算作中断：领取放开，草稿和工作记录保留。研究者要继续工作时启动 Pursue，按新规则开始。
- 第 2 条里还有东西靠着的被拒节点、第 3 条里读法含糊的 Challenge，要研究者来定，由 Coordinator 来问。问完之前只有那几支停着，其余照常进行。

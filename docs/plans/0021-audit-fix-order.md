# ADR-0021 审计修复顺序

## 当前平台优先级（2026-10-12）

平台规划以 [macOS 成熟度与后续平台开发地图](https://github.com/DengZhiyuan-math/proof-cli/issues/215) 为准。macOS 跑通并形成成熟系统是主动开发与验收主线；Windows、Linux 开发已移入低优先级 Fog，不再三平台同步推进。

现有跨平台 CI 保留为兼容性证据。Windows 慢测试、runner 波动和平台专属 job 分组不扩展当前 macOS 主线的工作范围。影响 macOS 正常使用的通用问题仍按实际影响排序。CI 通过、浏览器验证、真实 provider 运行和研究者的数学 Acceptance 分别记录；本次优先级变更不修改 CI 或分支保护。

以下日期记录保留历史事实，不表示继续承诺三平台同步开发。后续平台只有在 macOS 成熟度获研究者确认，并有明确使用需求与验证条件后，才由研究者决定是否从 Fog 转成决策票。

A proof project is a folder with a proof map in it: its theorem, the lemmas and claims it rests on, each with its own LaTeX proof. Start one here, or list a folder you already have.

From a terminal, proof init in a folder does the same and lists it here; proof map open opens a project's page.

Add an existing project

The folder must already hold a proof project (a .proof/project.sqlite3). Nothing in it is changed.

New project

Starts a proof project in the folder (made if it doesn't exist), exactly as proof init does, and opens it. Nodes are then created from the CLI with proof node create.

Forget this project?

It leaves this list only. The folder, its proofs and its git history stay exactly as they are; add it again any time.

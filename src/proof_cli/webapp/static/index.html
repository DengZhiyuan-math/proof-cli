Legacy decisions (made before passkeys)

These decisions were made before Human Review was signed, so they don't count yet. A legacy Reject still keeps its node closed, and a legacy dismissal keeps its Challenge closed. Re-sign the ones you stand by, or decline them. One tap covers every ticked item.

Foreign attestations (decisions another project signed)

Imported decisions never count here. Open a node to make the same decision yourself, or to enroll the other reviewer's key. An enrolled key only counts for decisions it signs here from now on.
